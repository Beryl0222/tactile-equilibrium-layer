# 稀疏平衡关系
本项目的合成接触图只用于数值研究，不连接设备。每个图含稳定节点名、有效位、COO有向边(u,v,a)、驱动X及样本权重。重复边是物理独立关系，贡献相加；无效节点及相关边不属于状态。状态Z的行顺序按本次有效节点名，图更正用revision区分。数组位置不是跨修订身份。
平衡方程为 Z=tanh(A Z W + X U + b)，其中A[u,v]累加有效边a，W为共享方阵，U为驱动投影，b逐特征广播。所有边上的W是同一个物理参数。正式状态需满足 ||Z-F(Z)||inf <= atol+rtol*||Z||inf；绝对容差1e-8，相对1e-6。非有限不接受。空有效图返回空状态且不计训练权重。热启动可只提供共有身份；新节点起点为0，其余起点不作正确性事实。
反向余量G作用于接受的Z；目标为sum(G*Z)。需解隐式转置系统，返回X/W/U/b的VJP及该系统相对残差，容差1e-6，允许的逆算子范数风险上限由请求给出。求解次数有限且证书不成立时无训练资格，前向资格不因此被覆盖。梯度按合格样本非负权重之和归一；全拒绝窗口不提交。前向参数代次与图修订必须保留。调用者明确关闭某前向，之后不能再申请其伴随。
候选参数是调用者提供的完整W/U/b，不要求项目选优化算法或自动修改候选。声明图族在`families`中列明A的最大绝对行和及允许节点/权重范围；稳定承诺是该族上F的Euclidean行特征最大范数诱导Lipschitz界不高于rho(小样本0.92)。可提交充分依据，不得仅以几条输入恰好收敛推断全族稳定。若无法证明，标证据不足并保留旧代；超界标不合格。接受窗口的梯度归属、样本权重及新代生效一并确认。
CPU支持1至2048节点、每节点至多12条边、状态维8至32。不能物化(ND)^2雅可比或N^2稠密邻接；小于16节点的直接对照不受此限制。每请求给前向/反向最大F或雅可比作用次数，重放也计数；常驻活动前向预算16MiB、临时工作区16MiB，原始只读X/COO不算临时复制但自行复制计入。算子的额度包含为同一请求所作的重放，资料读取工具不消耗该额度。
